=== 미션 1: 인증 유무 엔드포인트 비교 (포트 8001) ===

경로         보낸 키            상태     응답
----------------------------------------------------------------------------------------
/public    (없음)            200    {'endpoint': '/public', 'auth': False, 'message': '누구나 호출 가능합니다.'}  ✅ 인증 없는 엔드포인트 + 키 없음
/public    test-key-001    200    {'endpoint': '/public', 'auth': False, 'message': '누구나 호출 가능합니다.'}  ✅ 인증 없는 엔드포인트 + 올바른 키
/private   (없음)            401    {'detail': 'API Key가 필요합니다. X-API-Key 헤더를 포함해 주세요.'}  ✅ 인증 붙은 엔드포인트 + 키 없음
/private   wrong-key       401    {'detail': '유효하지 않은 API Key입니다.'}  ✅ 인증 붙은 엔드포인트 + 잘못된 키
/private   test-key-001    200    {'endpoint': '/private', 'auth': True, 'user': '사용자A'}  ✅ 인증 붙은 엔드포인트 + 올바른 키
----------------------------------------------------------------------------------------

요약
  /public  : Depends(verify_api_key) 없음 → 키와 무관하게 항상 200
  /private : Depends(verify_api_key) 있음 → 올바른 키일 때만 200, 그 외 401
  즉, 엔드포인트에 Depends() 한 줄을 추가하는 것만으로 접근 통제가 생깁니다.
